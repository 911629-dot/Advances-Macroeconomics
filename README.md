**QEM — UAB Macroeconomics Notes**

Graduate-level macroeconomics material from the QEM master's program at UAB. Covers financial frictions (CSV/Townsend, Kiyotaki-Moore, Jermann-Quadrini), banking theory (Diamond-Dybvig), incomplete markets (Bewley, Aiyagari, Huggett), optimal taxation (Ramsey/Chamley-Judd), New Keynesian models (Calvo pricing, NK Phillips Curve), monetary policy (Barro-Gordon, rules vs. discretion), and job search (McCall).
